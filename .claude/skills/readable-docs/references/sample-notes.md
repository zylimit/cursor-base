# 说明的范例

下面的项目是编的：一个图书馆的借阅系统。照这个详略与口吻写，别照它的内容。

## 表

```
## table:loans
一次借出：一行是一位读者借走一本书，从借出到归还。

读者在柜台或自助机上借书时由借阅接口写进来，`due_at` 按读者的等级算出；续借只改 `due_at` 与 `renew_count`，归还时填 `returned_at`，这一行不删。逾期罚金不在这里，在 `fines`，按 `loan_id` 连过来。

最容易看错的是「在借」：没有状态列，`returned_at` 为空就是在借；报丢的书 `returned_at` 也为空，要看 `lost_at`。
```

第一段一句话说清存的是什么、一行代表什么；后面讲什么时候写进来、之后谁改、连着哪张表看、最容易看错的地方。没有的不凑。

## 列

```
## column:loans.due_at
应还时间。借出时按读者等级的借期算出，续借一次往后推一个借期；过了这个时间没还就开始计罚金。

## column:loans.renew_count
已经续借了几次。到了读者等级允许的上限（`member_levels.max_renewals`）就不能再续。

## column:loans.channel
从哪里借的：`desk` 柜台、`kiosk` 自助机、`app` 手机预约后到馆取。取值在 `lending/channels.py` 的 `CHANNELS` 里。
```

写名字和类型看不出来的：取值各是什么意思、单位、空值代表什么、和别的列的关系。枚举把取值找全，说出在哪定义的。

## 组与整库

```
## group:lending
借还这一组讲一本书怎么到读者手里又怎么回来：`loans` 是主线，`reservations` 是排队等书的，`fines` 是逾期与丢失的罚金。先看 `loans`；另两张都按 `loan_id` 或 `book_id` 连着它。数据由借阅与归还两个接口写，报表只读。

## doc:db
全库分四块：馆藏（书目与每一册）、读者（账号与等级）、借还、报表。主线是「书目 → 册 → 借出 → 归还」：`titles` 是一种书，`copies` 是架上的每一册，借的是册不是书目。`members` 与 `copies` 是枢纽，一多半的表引用它们。带 `_log` 后缀的是流水、只增不改；带 `_snapshot` 的是每晚算出来的，可以重算。
```

## 模块

```
## module:lending
借书、续借、还书：读者把一册书借走到还回来这一段都归它。

它管到归还为止——逾期罚金的计算在「罚金与报丢」，它只在归还时把逾期天数交过去。借书走 `POST /api/loans`，先查读者有没有欠费（调「读者账号」）、这一册是不是在架，再写 `loans` 并把那一册标成借出。`loans` 与 `reservations` 主要由它写，别的模块只读。

改它要小心：借期怎么算在 `due_rules.py`，「报表」里的逾期统计直接引用了它，两边口径是连着的。待确认：自助机借书时不查欠费，是有意放开还是漏了。
```

第一段单独拿出来也要读得懂。后面讲它管到哪为止、一次典型的事从哪进到哪出、哪些表归它、改它要小心什么。拿不准的写「待确认」，不编。

## 导读

```
## doc:arch
这套系统给图书馆管书和借还：馆员编目上架，读者借书还书，馆长看报表。

代码分九个模块、三层。界面是馆员端与读者端两套页面；业务是编目、借还、罚金、读者账号；最下面是数据库连接、登录与权限。数据的主线是书目进来（编目）、借出去（借还）、逾期了算钱（罚金）、每晚汇总（报表）。

建议先读「公共支撑」——登录与权限是全系统共用的；再读「借还」，它写的两张表是别处读得最多的。
```

## 不要这样写

| 写成这样 | 毛病 | 该怎么写 |
|---|---|---|
| `due_at`：到期时间。 | 把列名翻译了一遍，读的人什么也没多知道 | 写它怎么算出来、过了会怎样 |
| 这张表是第三期为了支持续借加的，后来又加了 `channel` 列。 | 开发史。读的人要知道的是现在怎么用 | 讲现行的用法；改动的原文页面上另有一节 |
| 这张表应该是用来存借阅记录的。 | 「应该是」——没读写它的代码就下笔 | 读了写入的那段代码再写；真拿不准写「待确认：……」 |
| 例：张三借了《某某》，住在某某小区。 | 真实的人名、地名 | 例子一律编：「读者甲借了一本示例书」 |
| 页面上「入口」一栏是空的，所以它被列进了没人引用的清单。 | 描述页面当下的样子。页面跟着代码与生成器变，这句话过期了指纹也看不出来 | 讲代码本身：它由服务器进程直接拉起，没有别的文件引用它 |
| 包含 `loans.py`、`renew.py`、`return.py` 三个文件，提供 5 个接口。 | 复述事实清单，页面上已经有了 | 写把这些事实串起来的那几句 |
| 本期没有结束状态，预约一旦建立就一直有效。 | 「本期」「这一版」「暂时」——读的人不知道是哪一期，也分不清是有意这样还是还没做完 | 直接写现在怎样：「没有结束状态，预约一旦建立就一直有效」；有意不做与还没做完要分清的，把是哪一种写出来 |
