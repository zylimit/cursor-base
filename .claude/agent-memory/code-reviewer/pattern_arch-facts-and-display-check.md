2026-11-23 审人读文档第三期（架构）时每条都真复现过：

- **核对器按 `data-row` 属性比键 = 显示的字没人比**：把模块页文件格显示成别的路径、首页每行都链到第一个模块、依赖格显示成自己，check 0 条、测试全绿。攻法：突变显示文字而不动属性；再逐段列「页面上显示了、核对没比」的项（文件头说明、处理函数说明、入口、被谁依赖、外部包、循环 / 越层 / 没人引用清单、首页的读写与依赖数），每项一个突变。
- **代码根本身是包（有 `__init__.py`）还被当引用起点**：`proj/celery.py` 一类同名包装模块把三方 / 标准库名截走，生出假边、外部包消失。多个代码根同名文件「先试的赢」，脚本的同目录引用被解析到别的根。造两个夹具各一行就中。
- **没被挂载点到的路由器一律当最外层**：挂载写成函数调用、子应用用 `.mount()` 挂，完整路径少一段前缀却不是 null、接口页不标记。先列框架有几种挂法，再看取事实器认了几种。
- **「代码行号不上页面」要查说明文字**：没解析到的清单里「第 N 行起没闭合」「只取第一处：第 N 行」照样上页。攻法：全部代码文件顶上加三行重出，规模档归一后看残差。
- **性能**：每个常量跑一遍全文正则（8000 个常量约 2 秒，按平方涨）；截断上下文时每删一条就把整个对象重新序列化一次。按 1500 / 3000 / 6000 个文件计时看翻倍比例。

**Why:** 下游真数据（用同一套规则拿语法树对拍）全部对得上，这几类只有合成输入才露；核对器与测试按同一种读法读页面，错得一样，看不出来。
**How to apply:** 先做显示文字突变与「显示了没比」清单，再造包代码根 / 同名代码根 / 子应用挂载三个夹具，最后加三行对拍。结论分代码缺陷与契约字面导致的缺陷。相关：[[pattern-ddl-facts-and-page-redaction]] [[pattern-markdown-chunk-render-zero-loss]]
