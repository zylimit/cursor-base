# One-sentence statement of the lesson, as an instruction

What happened, in two or three sentences: the action taken, the outcome, and how the user
corrected it — quoting them where the wording matters.

Scenario: what the situation looked like when this bit. On a second occurrence, what the second
time looked like — that is the value, not the counter.

What to do instead, stated as an instruction a future session can follow without this context.

Scope: which stages, roles, and project kinds this applies to.

Exceptions: when it does not apply. A rule without a range is applied where it should not be.

Supersedes: which rule or lesson this replaces, by name — or `none`. Two coexisting rules fight.

Applied to: the file and section, the decision date, or the dispatch where this correction
already landed. `pending` means it has not taken effect yet.

Evidence: the command, output, diff, or conversation that demonstrated the problem.
